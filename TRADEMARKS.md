# Política de marca Q'Suene

El código de Q'Suene puede utilizarse conforme a GNU AGPLv3 o posterior. Esa
licencia no concede autorización para presentar productos derivados como si
fueran versiones oficiales de Q'Suene.

El nombre **Q'Suene**, su logotipo, iconos distintivos y elementos de identidad
visual oficial se reservan a Gonzalo Andrés Lucio.

Se permite mencionar Q'Suene de forma descriptiva, enlazar el proyecto, indicar
compatibilidad y comunicar honestamente que un producto deriva del proyecto. Una
versión modificada debe usar un nombre y una identidad propios, salvo autorización
expresa del titular de la marca.

No se permite usar la marca de una forma que sugiera patrocinio, aprobación,
origen oficial o afiliación inexistentes.
